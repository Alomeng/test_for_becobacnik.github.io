Основы HTTP

HTTP-запрос состоит из метода, адреса, заголовков и, иногда, тела.

GET
Получить данныеНапример, прочитать публикацию или список пользователей.
GET /posts/1
POST
Создать ресурс / отправить данныеОбычно передаёт данные в теле запроса.
POST /posts
PUT
Заменить ресурсЧасто заменяет представление ресурса целиком.
PUT /posts/1
PATCH
Частично изменить ресурсПередаёт только изменяемые поля.
PATCH /posts/1
DELETE
Удалить ресурсУдаляет ресурс, если API поддерживает эту операцию.
DELETE /posts/1
ⓘ

Важно: HTTP-метод сам по себе не гарантирует действие. Реальное поведение зависит от конкретного API. JSONPlaceholder — учебный сервис: изменения имитируются и не сохраняются как в настоящей базе данных.

PYTHON 3

Твой первый API-клиент

Получает публикацию, проверяет статус и сохраняет JSON в файл.

Скачать main.py ↓
python/main.py
import json
import requests

url = "https://jsonplaceholder.typicode.com/posts/1"

try:
    response = requests.get(url, timeout=10)
    print("HTTP status:", response.status_code)
    response.raise_for_status()

    post = response.json()
    print("Title:", post["title"])

    with open("response.json", "w", encoding="utf-8") as file:
        json.dump(post, file, ensure_ascii=False, indent=2)

    print("Ответ сохранён в response.json")

except requests.exceptions.RequestException as error:
    print("Ошибка запроса:", error)
except (ValueError, KeyError) as error:
    print("Ошибка данных:", error)
