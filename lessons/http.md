# Урок 1. HTTP

## Что такое HTTP

HTTP — протокол обмена сообщениями между клиентом (например, браузером или Python-скриптом) и сервером.

Запрос обычно включает:
- метод: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`;
- URL ресурса;
- заголовки, например `Accept` или `Content-Type`;
- необязательное тело запроса.

Ответ включает статус-код, заголовки и необязательное тело.

## Методы

- `GET` — получить представление ресурса;
- `POST` — отправить данные на обработку, часто для создания ресурса;
- `PUT` — заменить представление ресурса;
- `PATCH` — частично изменить ресурс;
- `DELETE` — запросить удаление ресурса.

Конкретное поведение определяется документацией API.

## Статус-коды

- `2xx`: запрос успешно обработан;
- `3xx`: перенаправление;
- `4xx`: проблема в запросе или правах клиента;
- `5xx`: ошибка на стороне сервера.

Частые коды: `200 OK`, `201 Created`, `204 No Content`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `429 Too Many Requests`, `500 Internal Server Error`.

## Практика

1. Открой `https://jsonplaceholder.typicode.com/posts/1`.
2. Измени номер `1` на `2`.
3. Сравни JSON-ответы.
4. Отправь тот же запрос через API-песочницу сайта.
5. Повтори запрос из Python с помощью `requests.get(url, timeout=10)`.

> Браузер может блокировать чтение некоторых ответов из-за CORS. Это политика безопасности браузера, а не отдельный HTTP-статус.
