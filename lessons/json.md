# Урок 2. JSON

JSON — текстовый формат обмена структурированными данными.

## Типы данных

- строка: `"hello"`;
- число: `42` или `3.14`;
- логическое значение: `true` или `false`;
- отсутствие значения: `null`;
- массив: `[1, 2, 3]`;
- объект: `{"name": "Alex"}`.

Имена свойств и строковые значения записываются в двойных кавычках. Запятые ставятся между элементами, но не после последнего элемента. Комментарии JSON не поддерживает.

## JSON в Python

```python
import json

text = '{"name": "Alex", "active": true}'
data = json.loads(text)  # JSON-строка -> dict Python
print(data["name"])

encoded = json.dumps(data, ensure_ascii=False, indent=2)
print(encoded)
```

`response.json()` в библиотеке `requests` декодирует тело HTTP-ответа в Python-объект. Если тело не содержит корректный JSON, декодирование вызовет ошибку.
