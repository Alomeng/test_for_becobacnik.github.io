# HTTP Lab

Интерактивная учебная лаборатория для практики HTTP, JSON, REST API и Python.

## Возможности

- справочник HTTP-методов и статус-кодов;
- браузерная API-песочница (GET/POST/PUT/PATCH/DELETE);
- просмотр статуса, времени ответа, размера и доступных заголовков;
- JSON-проверка, форматирование, минификация и сводка типов;
- Python-скрипт на `requests`, сохраняющий ответ в `response.json`;
- практические задания и уроки в `lessons/`;
- тёмная и светлая темы.

## Запуск сайта локально

Открой `index.html` в браузере или запусти простой статический сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создай публичный репозиторий GitHub, например `http-lab`.
2. Загрузи в репозиторий содержимое этой папки.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, затем сохрани.
6. Дождись публикации. Адрес обычно имеет вид `https://USERNAME.github.io/http-lab/`.

GitHub Pages обслуживает статические файлы. Он не запускает `python/main.py` на сервере. Python-скрипт скачивается и запускается на твоём компьютере.

## Запуск Python-практикума

Требуется Python 3.10+ и интернет-соединение.

Windows:

```powershell
cd python
py -m pip install -r requirements.txt
py main.py
```

Если команда `py` не работает, попробуй `python -m pip install -r requirements.txt`, затем `python main.py`.

Скрипт получает публикацию по ID, выводит HTTP-статус и заголовок, а затем сохраняет ответ в `response.json` в текущей рабочей папке.

## Ограничения браузерной песочницы

- Публичные API могут быть недоступны временно или менять условия использования.
- Браузерный `fetch` подчиняется CORS. Если API не разрешает запросы с этого сайта, браузер не даст прочитать ответ. Это не исправляется настройками самого GitHub Pages.
- Не вводи секреты в публичную песочницу и не отправляй их сторонним сервисам.
- JSONPlaceholder предназначен для обучения и имитирует операции записи; изменения не являются постоянными.
